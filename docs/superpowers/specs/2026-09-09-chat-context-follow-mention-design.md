# 聊天上下文改造：自动跟随 + @ 引用 — 设计文档

日期：2026-09-09 | 状态：已评审（待实现） | 方案：A（跟随状态机 + chips 行）

参考图：`aicode_edit.jpg`（输入框上方 `+` + 文件 chips，选中行显示行号）。

## 1. 背景与目标

去掉主界面 `+File` / `+Folder` 按钮，改为：

1. 自动跟随编辑器：chips 区常驻显示当前打开的文件，切换自动更新，可×解绑；
2. `@` 引用文件/目录：输入 `@` 弹出项目文件列表，打字过滤、选目录进入、可直接关联；
3. 展示形式以参考图为准：输入框上方一行 `+` 按钮 + chips（图标 + 文件名 + 可选行号 + ×）。

非目标：改动发送/流式链路、改动 Provider 配置、改动会话持久化格式。

## 2. 架构与组件（§1 已确认）

- **删除**：`addFileButton` / `addFolderButton`、`chooseContext()`、`JFileChooser` 流程；底部旧 `chipsPanel` 合并到输入框上方的新 chips 行。
- **新增 `EditorFollowTracker`**（独立类，可单测）：监听编辑器切换 + 选中变化（300ms 防抖），输出当前自动跟随项（无选中→FILE，有选中→SNIPPET 行号）。自动项只放内存，不进会话持久化。
- **新增 `MentionPopup`**（@ 选择器）：JBPopup + 列表，起点为项目根目录，打字过滤，目录可进入、可直接关联（FOLDER），文件确认即关联。
- **chips 行**（输入框上方）：`+` 按钮（直接打开 MentionPopup）+ chips（图标 + 文件名 + 行号 + ×）。数据沿用 `StoredContextEntry`，加来源标记区分自动 / 手动（决定×行为）。
- **保留**：右键 Send to AiCode（改为“确保 snippet chip + 聚焦聊天”）；“清空”按钮语义改为清除手动 chips + dismissed 当前跟随项。

## 3. 数据流与交互细节（§2 已确认）

- **跟随更新链**：编辑器切换 / 选中变化 → 300ms 防抖 → `EditorFollowTracker` 算期望项 → 与当前自动 chip 比对，不一致才刷新。× 点自动 chip → 记录 dismissed（文件路径 + 选中行号），切换到其他编辑器后清除 dismissed。
- **@ 触发**：输入框 `DocumentListener` 检测光标前的 `@xxx` token（@ 后无空格）→ 光标附近弹 `MentionPopup`，`xxx` 作初始过滤；选中文件 → 删除 `@xxx` 文本、加 chip；Esc 关闭；`+` 按钮 = 无 token 直接打开。
- **目录行**：目录显示文件夹图标 + `/` 后缀；Enter / 双击进入下级；单独“关联此目录”操作 → FOLDER chip。
- **发送组装**：手动 entries（会话持久化）+ 当前自动项（transient）合并 → `ContextResolver` 解析；SNIPPET 只发选中行。
- **会话切换**：手动 chips 跟会话走（现有持久化）；自动项不跟会话，每次按当前编辑器重算。

## 4. 错误处理（§3 已确认）

- 文件被删/移走：沿用 `ContextResolver` 占位（`[File not found…]`），chip 文件名置灰 + tooltip，不自动删除；popup 跳过不存在项。
- 大目录：popup 只列直接子级，上限 500 项，超限提示继续输入过滤；过滤放后台线程。FOLDER 关联沿用 200 文件 / 40 万字符上限，超限截断 + info 气泡说明。
- 二进制文件：popup 允许选中，发送时按现有规则跳过并在 transcript 提示一行。
- 非本地文件（jar 包内等）：`LocalFileSystem` 解析失败时自动 chip 自动隐藏，不报错。

## 5. 测试验收（§4 已确认）

单元测试：`@` token 提取（含行中多 @、中文）、目录导航路径拼接、dismissed 逻辑。
手动验收（runIde）：①切换编辑器跟随；②选中→行号 chip→取消选中恢复；③× 后切走切回重现；④@ 过滤/导航/关联文件与目录；⑤`+`/Esc/清空语义；⑥发送上下文正确（warn 日志 + 回复引用）；⑦旧按钮消失；⑧右键 Send 可用。

## 6. 需求决策记录

1. 自动关联时机 → 实时跟随编辑器（发送时快照 / 仅选中代码落选）
2. @ 起点目录 → 项目根目录
3. × 解绑语义 → 只移除当前项，切换后继续跟
4. @ 选中形式 → chips（以参考图为准，文本插入落选）
5. `+` 按钮行为 → 打开 @ 文件选择器
6. 行号 chip 内容 → 只发选中行
7. @ 中目录 → 可直接关联，保留现有配额限制
8. 选中代码跟随 → 自动生成行号 chip
9. 实现方案 → A（B 纯文本 / C 最小改动落选）
